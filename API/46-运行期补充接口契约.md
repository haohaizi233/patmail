# 运行期补充接口契约

本文档补录 PatMail 插件在生产运行期（`patmail-extension/src/api/transport.ts`）已稳定接入、但早先未在入口索引表单独建档的 EASY 原站接口契约，涵盖会话探测、费用辅助树、审批流程、递交版本判定、代理所检索及统一文件取件入口。

---

## 1. 会话与操作人身份（`Login.ashx`）

### GetUserModel

- **入口**：`POST /AjaxServers/Login.ashx`
- **用途**：探测当前 EASY 标签页登录会话有效性，并读取当前操作人身份（显示名、用户 GUID）。
- **请求参数**：

| 参数 | 必填 | 示例 | 说明 |
|---|---|---|---|
| `Call` | 是 | `GetUserModel` | 动作名 |
| `log_pagename` | 否 | 空字符串 `""` | 页面标识 |

- **响应要点与现场边界**：
  - 已登录时返回包含 `ClientInfo` 与用户信息对象的 JSON；**注意生产站实测已登录状态下 `ClientInfo.Result` 仍可能为 `false`**，登录态判定必须以 `ClientInfo.IsLogin === true` 且 `ClientInfo.Status !== false` 为准。
  - 无有效会话时，除标准 `ClientInfo.IsLogin === false` 或 302 跳转登录页外，原站常直接返回短 HTML 片段 `出错了!`（长度 <= 500 且无 `<html>` 壳），传输层需将其明确识别为 `SESSION_EXPIRED`。
  - 高并发下载/命名打满连接时 `GetUserModel` 可能超时（插件放宽至 30s）；超时仅代表检测暂不可达，不能将已确认登录态误判为掉线。

## 2. 费用查询辅助弹窗与动态树（`Report.ashx` / `BaseInfo.ashx` / `Common.ashx`）

以下接口均服务于 `Forms/Bill/FeeSearch.aspx`（详见 [44-费用查询.md](44-费用查询.md)）。

### GetCustomerTreeData（`Report.ashx`）

- **入口**：`POST /AjaxServers/Report.ashx`
- **用途**：客户名称 / 排除客户名称二级弹窗（原站 `ShowIhgSelect` / `IhgSelect.aspx`）的实时关键词检索。
- **请求参数**：

| 参数 | 必填 | 说明 |
|---|---|---|
| `Call` | 是 | 固定 `GetCustomerTreeData` |
| `searchKey` | 是 | 搜索关键词（单引号需转义为 `''`；空字符串可返回默认分页前段） |
| `log_pagename` | 否 | `FeeSearch.aspx` |

- **响应结构**：

```json
{
  "CustList": [
    {
      "id": "customer-guid",
      "name": "示例科技有限公司",
      "tel": "",
      "email": ""
    }
  ],
  "ClientInfo": { "IsLogin": true, "Status": true, "Result": true }
}
```

### GetTreeApplicant（`Report.ashx`）

- **入口**：`POST /AjaxServers/Report.ashx`
- **用途**：根据已选客户 GUID 集合实时加载对应「申请人」树；仅选中申请人后才解锁 `first_applicant`（限第一申请人）。
- **请求参数**：

| 参数 | 必填 | 说明 |
|---|---|---|
| `Call` | 是 | 固定 `GetTreeApplicant` |
| `customer_ids` | 是 | 已选客户 GUID，英文分号 `;` 拼接 |
| `log_pagename` | 否 | `FeeSearch.aspx` |

- **响应结构**：返回 `TreeApplicant[]`，节点含 `id`、`name`、`pid` / `pId`、`TreeType`（`Dept` 或 `is_branch=1` 表示分组节点不可勾选）。

### GetProducts（`BaseInfo.ashx`）

- **入口**：`POST /AjaxServers/BaseInfo.ashx`
- **用途**：读取费用高级查询「产品类别」树形字典。
- **请求参数**：`Call=GetProducts`、`log_pagename=FeeSearch.aspx`。
- **响应结构**：`Products[]`，标准树节点（`id`、`name`、`pid`/`pId`）。

### LoadTechnical（`Common.ashx`）

- **入口**：`POST /AjaxServers/Common.ashx`
- **用途**：读取费用高级查询「技术领域」树形字典。
- **请求参数**：`Call=LoadTechnical`、`Key=`（空字符串拉取全量）、`log_pagename=FeeSearch.aspx`。
- **响应结构**：`Technical[]`，标准树节点（`id`、`name`、`pid`/`pId`）。

## 3. 流程审批、人员浮窗与递交版本探测（`Common.ashx` / `CaseInfo.ashx`）

### ShowUserInfo（`Common.ashx`）

- **入口**：`POST /AjaxServers/Common.ashx`
- **用途**：原站姓名悬停浮窗接口；用于递交导出与流程历史补齐办理人所属部门与联系信息。
- **请求参数**：`Call=ShowUserInfo`、`user_id={GUID}`。
- **响应结构**：主体为 `User` 对象（兼容部分环境直接平铺于顶层），常用字段：`cn_name`、`dept_full_name`、`email`、`tel`。

### GetProcessByTypeAP（`Common.ashx`）

- **入口**：`POST /AjaxServers/Common.ashx`
- **用途**：读取待办中心 `ProcessNew.aspx`「提案流程」页签列表（与 `GetProcessByTypeEF` 递交流程、`GetProcessByTypeCO` 对应）。
- **请求参数**：携带标准分页与 `colsel` 列集合：
  ```text
  ;undefined;undefined;apply_name;tapp_no;tcase_volume;ctrl_proc;case_type_zh_cn;apply_type;business_type;customer_name;cn_name;create_time;node_name_zh_cn;update_time;now_remark;urgency_name;
  ```
- **响应结构**：标准 `TableRows` + `TableRowsCount` + `ClientInfo`。

### GetIsNewCPC（`CaseInfo.ashx`）

- **入口**：`POST /AjaxServers/CaseInfo.ashx`
- **用途**：打开递交流程表单前只读探测目标递交记录属于新版 CPC 表单还是旧版表单，以决定跳转路径。
- **请求参数**：`Call=GetIsNewCPC`、`filing_id={GUID}`、`log_pagename=ProcessNew.aspx`。
- **响应结构**：返回新版 CPC 布尔标识与 `ClientInfo`。

## 4. 代理所维度案件检索（`AgencyAction.ashx`）

### AgencySearchCase

- **入口**：`POST /AjaxServers/AgencyAction.ashx`
- **用途**：按客户文号批量反查案件主键 `case_id`（用于案件联系人导出与关联查询）。
- **请求参数**：

| 参数 | 必填 | 示例 | 说明 |
|---|---|---|---|
| `Call` | 是 | `AgencySearchCase` | 动作名 |
| `Element` | 是 | 实体编码 XML | 含 `&lt;case_volume_customer&gt;`（多文号换行分隔）、`&lt;is_proc&gt;1&lt;/is_proc&gt;` 等节点 |
| `is_proc` | 是 | `false` | 是否展开处理事项 |
| `pageIndex` / `pageSize` | 是 | `1` / `50` | 分页参数 |
| `_PK` | 是 | `case_id` | 主键列名 |
| `searchKey` | 否 | `""` | 快速检索词 |
| `page_user_id` | 否 | 操作人 GUID | 当前页用户 ID |
| `log_pagename` | 否 | `CaseList.aspx` | 来源页 |

- **响应结构**：标准 `TableRows[]`（含 `case_id`、`case_volume`、`case_volume_customer` 等）与 `TableRowsCount`。

## 5. 统一文件取件入口（`FileHandler.ashx`）

- **入口**：`GET /AjaxServers/FileHandler.ashx?guid={GUID}[&file_size={bytes}]`
- **用途**：原站 `GetFile(guid, file_size)` 统一文件下载入口，承接文件批量打包（`BaseInfo.ashx?Call=DownLoad` 返回的 ZIP）以及高级导出（`Report.ashx?Call=ExcelFeeList*` 返回的 Excel）。
- **与 `FileHandlerNew.ashx` 区别**：`FileHandlerNew.ashx` 为早期抓包样本记录的下载路径；当前生产站 `public.js` 的 `GetFile()` 及高级导出统一指向 `/AjaxServers/FileHandler.ashx`。
- **安全校验约束**：
  - `guid` 必须为标准 36 位 UUID（`[0-9a-f]{8}-...`），`file_size` 仅接受纯数字；
  - 依赖同源 EASY 登录 Cookie 鉴权，响应通过 `Content-Disposition` 声明真实文件名及扩展名。

## 6. 插件扩展内部通信与调度

本文档补录的 10 个运行期接口在 PatMail 中的消息映射、转发白名单与超时预算一览：

| EASY 入口 / Call | 插件 `MessageType` | 转发白名单 | 转发超时预算 | 调用方 / 用途 |
|---|---|---|---|---|
| `Login.ashx / GetUserModel` | `CHECK_SESSION` / `CANCEL_SESSION_CHECK` | `PAGE_FORWARD` | `30s`（传输层 `30s`） | `SessionService` 会话心跳与账号切换检测 |
| `Report.ashx / GetCustomerTreeData` | `SEARCH_FEE_CUSTOMERS` | `PAGE_FORWARD` | `30s` | `FeeCustomerPickerModal.vue` 二级客户选择弹窗 |
| `Report.ashx / GetTreeApplicant` | `LOAD_FEE_APPLICANTS` | `PAGE_FORWARD` | `30s` | `FeeSearchQuery.vue` 申请人联动多选树 |
| `BaseInfo.ashx / GetProducts`、`Common.ashx / LoadTechnical` | `LOAD_FEE_INIT` | `PAGE_FORWARD` | `70s`（`slow`） | `FeeSearchQuery.vue` 初始化与「校对最新字典」并发拉取 |
| `Common.ashx / ShowUserInfo` | `READ_USER_INFO` | `PAGE_FORWARD` | `30s` | `FilingSearchQuery.vue` 导出时补齐办理人部门（含 `userInfoCache`） |
| `Common.ashx / GetProcessByTypeAP` | `LIST_MAIL_PROCESSES` | `PAGE_FORWARD` | `70s`（`slow`） | 提案流程待办列表查询 |
| `CaseInfo.ashx / GetIsNewCPC` | `OPEN_EASY_FORM` | `PAGE_FORWARD` | `30s` | `resolveProcessForm()` 打开递交流程前探测新旧 CPC 表单 |
| `AgencyAction.ashx / AgencySearchCase` | `EXPORT_CASE_CONTACTS` | `PAGE_FORWARD` | `180s` | 案件联系人批量反查导出 |
| `GET /AjaxServers/FileHandler.ashx` | `SAVE_DOWNLOAD`（内容脚本 -> 后台） | 严格 URL 正则白名单 | `30s` 受理 + 原生下载 | ZIP 打包下载与服务端 Excel 导出统一落盘（失败降级隐藏 `iframe`） |
