## GetFileName

生成下载用的文件名，不是按单个 `file_id` 取文件信息。

```http
POST /AjaxServers/CaseInfo.ashx
```

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetFileName` |
| file_ids | 是 | 分号分隔的文件 GUID |
| new_filename | 是 | 与 `file_name_type` 逐段对应，段之间用分号 |
| file_name_type | 是 | 每段是 `colname` 或 `txt`。抓包示例：`colname;txt;colname;txt;colname` |
| childpath | 否 | 子目录列名。不用时为空 |
| zip_name | 否 | 压缩包名称模板 |
| zip_file_name_type | 否 | 压缩包名称的 `colname` / `txt` 序列 |
| log_pagename | 否 | `FileSearch.aspx` |

`colname` 段的 `new_filename` 取值来自 `GetFlowdirection.DownLoadFileName.value`。`txt` 段是用户输入的固定文字。

只传 `file_name_type=colname` 且 `new_filename` 为空时，返回「系统繁忙，请求失败，请稍后重试！」。

用一个文件 ID、`new_filename=file_name`、`file_name_type=colname`、压缩包参数为空做只读调用时，`ClientInfo.Status=true`，`Message=null`。响应字段：

| 字段 | 说明 |
|---|---|
| file_names | 生成的文件名，多个时用分号连接 |
| zip_names | 压缩包名，本次空字符串 |
| child_path | 子目录，本次空字符串 |
| ClientInfo | 公共响应 |

没有配置重命名时，页面改调 `GetFileNameByConfig`，参数是 `file_ids`、`zip_name`、`zip_file_name_type`。成功回调同样读 `file_names` 和 `zip_names`。这次没有单独调用。

生成出的具体文件名没有写入本文。

## GetFileTempNameList

当前登录用户保存的下载文件名模板。查询条件模板见 `SearchQueryHisList`，可选列名见 `GetFlowdirection.DownLoadFileName`。

```http
POST /AjaxServers/BaseInfo.ashx
```

HAR `文件管理入口` 的请求只有：

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `GetFileTempNameList` |
| log_pagename | 否 | `FileSearch.aspx`。发文页抓到的是 `FileSearchMail.aspx` |

响应键是 `TempNameList`。2026-09-28 只读核对 35 条。页面用 `id` 做下拉值，用 `temp_name` 做显示名。选中后在本地套用 `new_filename` 和 `file_name_type`，不再发请求。

| 字段 | 说明 |
|---|---|
| id | 模板 ID |
| temp_name | 模板名称 |
| user_id | 所属用户 |
| new_filename | 分号分隔。`colname` 段是列名，`txt` 段是固定文字 |
| file_name_type | 与上一段逐段对应，取值 `colname` 或 `txt` |

没有模板时按 `TempNameList` 缺失或 `null` 处理。具体模板名称没有写入本文。

同页还有 `GetFileTempZipNameList`，响应键也是 `TempNameList`，填的是压缩包名称下拉。这次没有单独保存它的正文。

## SaveFileTepmName

保存下载文件名模板。Call 名里的 `Tepm` 是页面原文（`FileSearch.js` 的 `FileManager.SaveFile`）。2026-11-01 抓包已核对。

```http
POST /AjaxServers/BaseInfo.ashx
```

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `SaveFileTepmName` |
| temp_name | 是 | 模板名称。页面文本框，非空才提交 |
| new_filename | 是 | 与 `file_name_type` 逐段对应，段之间用分号。抓包示例 `app_no;-;case_name;-;file_desc` |
| file_name_type | 是 | 每段是 `colname` 或 `txt`。抓包示例 `colname;txt;colname;txt;colname` |
| log_pagename | 否 | `FileSearch.aspx` |

页面提交前先自检，都不发请求：配方为空提示「请配置下载文件名称」，模板名称为空提示「请填写模板名称」。`colname` 段取 `GetFlowdirection.DownLoadFileName.value`，`txt` 段是用户输入的固定文字；没选的空段跳过，不进配方。

响应形态 `obj:ClientInfo,TempNameList`，`TempNameList` 是保存之后这个账号的完整模板列表，元素字段见上面的 `GetFileTempNameList`。成功条件是 `ClientInfo.Result=true`；失败时页面直接弹 `ClientInfo.Message`。抓包样本（同名模板存过两次，两行各有自己的 `id`）：

```json
{
  "ClientInfo": { "IsLogin": true, "Status": true, "Message": null, "Result": true },
  "TempNameList": [
    { "temp_name": "…", "user_id": "…", "new_filename": "app_no;-;case_name;-;file_desc", "file_name_type": "colname;txt;colname;txt;colname", "id": "045eb1fc-e77a-4d50-98df-cbfcc9e5f4e7" },
    { "temp_name": "…", "user_id": "…", "new_filename": "app_no;-;case_name;-;file_desc", "file_name_type": "colname;txt;colname;txt;colname", "id": "fe1c69c1-961c-43be-9e1d-f29b9c030e6e" }
  ]
}
```

同名同配方是两行两份 `id`：保存总是新增一行，不是覆盖。页面收下新的 `TempNameList` 后整体重建模板下拉。

## DeleteTemp

删除下载文件名模板。页面入口在文件检索页的模板下拉旁（`FileSearch.js` 的 `FileManager.DelTemp`）。2026-11-01 抓包已核对。

```http
POST /AjaxServers/BaseInfo.ashx
```

| 参数 | 必填 | 说明 |
|---|---|---|
| Call | 是 | 固定 `DeleteTemp` |
| temp_id | 是 | 要删除的模板 `id`，即 `TempNameList` 行的 `id` |
| log_pagename | 否 | `FileSearch.aspx` |

响应和 `SaveFileTepmName` 同形态：`TempNameList` 是删完之后的完整列表，被删的那行不再出现。成功条件是 `ClientInfo.Result=true`，失败时页面弹 `ClientInfo.Message`。抓包样本是删掉上文两行里的 `045eb1fc-…`，响应里只剩 `fe1c69c1-…` 一行。

压缩包名称模板的两个写接口是 `SaveFileTepmNameZip`（`new_filename`、`temp_name`、`file_name_type`）和 `DeleteZipTemp`（`temp_id`），响应键同样是 `TempNameList`，页面逻辑与上面成对一致。这次没有抓包核对。

## 下载

`public.js` 的 `DownLoad(file_no, file_name, model, zip_name, zip_pwd, type, childpath)`。文件查询传入的 `model` 是 `FILE`。

1. 租户配置 `FileUpload / is_not_approval` 打开时，先调用 `CaseInfo.ashx` 的 `GetApprovalByFileNo`，参数 `file_no`。`flag` 为 `"True"` 才继续。
2. `POST /AjaxServers/BaseInfo.ashx`，`Call=DownLoad`。参数：`file_no`、`file_name`、`zip_name`、`zip_pwd`、`down_type`、`model`、`childpath`。2026-10-26 抓包（文件查询页，7 个文件）的完整表单是：

```text
Call=DownLoad&file_no=<分号分隔的 file_no>&file_name=<分号分隔的生成名>&zip_name=&zip_pwd=&down_type=&model=FILE&childpath=&log_pagename=FileSearch.aspx
```

`file_no` 是列表行的 `file_no`（`A00110397537` 这类），不是 `file_id`；`file_name` 与它逐项对应，取 `GetFileName` 的 `file_names`。

3. 响应含 `error`、`error_message`、`file_guid`、`file_size`、`ClientInfo`。`file_guid` 非空就是打包成功：本次样本 `ClientInfo.Result` 仍是 `false`、`error` 为 `true`，`error_message` 是「文件不存在或权限不足,您共0个文件下载失败！」，页面照样取文件。`error_message` 里的「共 N 个文件下载失败」才是真失败的文件数，N 为 0 时页面仍会弹一次确认框。`file_size` 可以缺失。
4. 取文件是 GET：

```text
/AjaxServers/FileHandler.ashx?guid=<file_guid>&file_size=<file_size>
```

返回的压缩包条目名 = 第 2 步传入的 `file_name`，本次 7 个条目与 7 个生成名逐一相同；包本身的名字是时间戳（`1793001423.zip`）。生成名由 `GetFileName` 的模板拼出来，`colname` 段直接取列值，例如 `app_no` 的 `202610026334.9` 会原样进名字（`202610026334.9-清洗液监测系统及其监测方法-专利申请受理通知书.pdf`）；模板不支持按字符改写，要去掉申请号校验点只能在调用方改 `file_name`。

还有 `DownLoadZip`、`DownLoadFiles`，分别调用 `BaseInfo.ashx` 的 `DownLoadZip`、`DownLoadFiles`。批量打包另有 `FileHandlerNew.ashx?guid=`。这三步都没有重新执行。

## 上传

HAR 里没有上传正文。页面有两条入口：

1. 弹层 `Forms/UploadFile.aspx?model=CASE&Call=CommUpload&objid=<file_id>&filedesc=<GUID>&filetype=<GUID>`。
2. 拖拽上传打开 `Forms/UploadFileNew.aspx`，由 `CommDragUploadNotices` 初始化。允许的扩展名来自 `Common.ashx` 的 `GetAccepttype`，字段 `Accepttype.accept_file_ext`，分号分隔。

上传完成后，收文窗口调用 `CaseInfo.ashx` 的 `AddReceiveFile`，参数 `file_id`、`proc_id`。成功时返回 `ReceiveFileList`。

旧文档里的 `SaveFile`、`AddFile` 不是案件附件保存。下载文件名模板的读取和保存见上面的 `GetFileTempNameList`。`AddFile` 这个 Call 没有出现。
