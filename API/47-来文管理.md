# 来文管理 NoticeInfo

主页面：`Forms/Patent/NoticeInfo.aspx` / `Scripts/Page/Patent/notice.js?v=2.6.09.02`  
主业务 Handler：`POST /AjaxServers/Notice.ashx`、`POST /AjaxServers/FilingApiAction.ashx`、`POST /AjaxServers/UploadFile.ashx`、`POST /Forms/MultiUPload/UploadMethod.ashx`  
公共字典 Handler：`POST /AjaxServers/Common.ashx`、`POST /AjaxServers/CaseInfo.ashx`、`POST /AjaxServers/BaseInfo.ashx`

公共约定见 [00-通用约定.md](00-通用约定.md)，早期单次抓包样本字段骨架见 [25-官文.md](25-官文.md)，通用高级导出 XML 列协议见 [45-高级导出与模板协议.md](45-高级导出与模板协议.md)，全量索引见 [README.md](README.md)。

> [!IMPORTANT]
> **只读字典接口的 `ClientInfo.Result` 约定**：实测 `GetApplyType`、`GetAgency`、`GetDirectionType`、`GetNolaiutoCount`、`GetCPCTzsDate` 等只读接口在正常返回业务数据时，`ClientInfo.Result` 仍可能为 `false`，同时 `ClientInfo.Status` 为 `true`、`ClientInfo.IsLogin` 为 `true`。初始化与字典解析不得按 `Result === true` 判错，应优先检查 `IsLogin !== false` 与目标数据键是否存在。

### 2.3 其余页签检索参数与静态枚举

1. **来文下载（`FilingApiAction.ashx / GetUnProcessTzsList`）**
   - 参数：`account`（CPC 账号 `id`）、`casename`、`appno`、`startTime`、`endTime`、`status`（`''`=请选择、`unprocess`=未解析、`process`=已解析）、`pageIndex`、`pageSize`。
2. **专利电子证书下载（`FilingApiAction.ashx / GetCertList`）**
   - 参数：`account`、`casename`、`appno`、`startTime`、`endTime`、`xlh`（发文序列号）、`status`、`pageIndex`、`pageSize`。
   - `status` 枚举：`''`=全部、`1`=CPC官方-待下载、`2`=CPC官方-解析失败、`3`=CPC官方-解析成功、`4`=唯德系统-已下载未导入、`5`=唯德系统-导入失败、`6`=唯德系统-导入成功。
3. **来文二次下载（`FilingApiAction.ashx / GetReplayTzsList`）**
   - 参数：`account`、`applyType`、`applyNo`、`caseName`、`noticeName`、`xlh`、`startTime`、`endTime`、`pageIndex`、`pageSize`。
   - `applyType` 枚举：`''`=请选择、`1`=国家申请、`2`=PCT国际阶段、`3`=外观海牙。
4. **异常来文（`GetHandNoticeList`）、异常处理记录（`GetHandHisList`）、无需导入来文（`GetNolaiuto`）**
   - 服务端参数：`pageIndex`、`pageSize`、`log_pagename=NoticeInfo.aspx`；其中 `GetHandNoticeList` 与 `GetHandHisList` 额外接收 `assayer`。
   - **当前页本地关键词过滤**（对齐原站 `#ErrorNoticeInput` / `#ErrorInput` / `#NOInput`）：大小写不敏感匹配 `oa_name`、`oa_code`、`file_desc_code`、`ShenQingH`、`cn_applicationnumber`、`case_volume`、`customer_name`、`case_name`、`FaMingMC`、`assayer`、`cn_name`、`TongZhiShuBH`、`fawenxlh`、`file_name`、`oa_error_msg`。
5. **电子申请清单对比（`Notice.ashx / GethandExcelList`）**
   - 参数：`is_import`（`''` / `1` / `0`）、`is_download`（`''` / `已下载` / `待下载`）、`is_handle`（`''` / `1` / `0`）、`pageIndex`、`pageSize`、`log_pagename=NoticeInfo.aspx`。

### 2.4 查询响应判定与行主键规则

- **列表主体**：读取 `TableRows[]`（回退 `rows[]`）；总条数依次读取 `raw.TableRowsCount`、`raw.total`、`TableRows[0].TableRowsCount`（原站顶层常返回数字字符串如 `'8006'`，需兼容 string 与 number）。
- **特殊状态识别**：
  - `ClientInfo.IsLogin === false` -> 会话失效（`SESSION_EXPIRED`）；
  - `ClientInfo.Result === false && ClientInfo.Message === '401'` -> CPC 分支机构账号需前往 EASY 原站「来文管理」完成扫码登录（`needCpcLogin = true`）；
  - `ClientInfo.Status === false && ClientInfo.Message` -> 业务失败（`BUSINESS_ERROR`）。
- **行唯一主键（`noticeRowKey`）**：
  - `download` / `cert` / `replay`：优先取 `fid`；
  - `handExcel`：优先取 `doc_no`；
  - 其余页签依次回退 `oa_id` -> `id` -> `sn`。

## 4. `FilingApiAction.ashx` CPC 鉴权校验与异步轮询流

### 4.1 CPC 账号登录态校验

| Call | 读写 | 参数 | 响应与判定 |
|---|---|---|---|
| `CheckUserStatus` | 只读 | `id`（CPC 账号 GUID） | 当所选账号标签包含 `_`（分支机构账号）时执行校验；返回 `ClientInfo.Result === false && ClientInfo.Message === '401'` 表示需要扫码登录 |
| `GetCpcTzsUser` | 只读 | 无 | 返回 `TableRows[]`（含 `id`、`user_name`、`out_time`）；若 `user_name` 含 `_` 且 `Number(out_time) > 1`，判定该分支机构账号扫码登录已过期 |

### 4.2 异步列表拉取、解析下载与删除

以下触发操作在通过写开关及 CPC 登录态校验后执行，除删档外均采用**「触发 Call -> 轮询 Status Call」**机制：

| 业务动作 | 触发 Call | 触发参数 | 轮询 Status Call | 轮询Busy提示与参数 |
|---|---|---|---|---|
| 从 CPC 获取官文列表 | `GetTzsList` | `account`, `casename`, `appno`, `startTime`, `endTime`, `status` | `GetTzsListStatus` | Busy 文案 `'通知书下载中,请稍等!'`；2s 间隔最多轮询 20 次 |
| 解析并下载通知书（含二次下载） | `ProcessTzsList` | 全量：`account`, `casename`, `appno`, `startTime`, `endTime`, `status`<br>勾选：`account`, `startTime`, `endTime`, `fids`（`;` 拼接）, `xlh`（`;` 拼接） | `ProcessTzsListStatus` | Busy 文案 `'通知书处理中,请稍等!'`；2.5s 间隔最多轮询 25 次 |
| 二次下载状态回查 | — | 勾选 `isReplay && fids.length > 0` 时下载轮询后调用 | `GetReaplyTzsStatus` | 参数 `fids`（`;` 拼接），返回 `rows[]` 更新每行 `status`、`remark`（注意原站拼写 `Reaply`） |
| 从 CPC 获取电子证书列表 | `GetCpcCertList` | `account`, `casename`, `appno`, `startTime`, `endTime`, `status`, `xlh` | `GetCertListStatus` | Busy 文案 `'专利证书列表获取中,请稍等!'`；2s 间隔最多轮询 20 次 |
| 下载并解析电子证书 | `DownloadAndAnalyseCert` | 固定 `account`；勾选模式附 `fids`、`;` 拼接的 `xlh` | `GetAnalyseCertStatus` | Busy 文案 `'专利证书解析中,请稍等!'`；2.5s 间隔最多轮询 25 次 |
| 删除待下载通知书记录 | `DeleteOaInfoByFids` | `fids`（`;` 拼接） | — | 同步操作，删除后仍可于「来文二次下载」重新下载 |

> [!NOTE]
> 轮询状态判定规则：`ClientInfo.IsLogin === false` 立即中止并标记会话过期；`ClientInfo.Result === true` 判定完成；`ClientInfo.Message` 非空且既非对应 Busy 提示、也不匹配 `/请稍等\|处理中\|下载中\|解析中/` 时按原站失败原因返回。

**响应分流**：
- 若 `ClientInfo.Result === false`：直接报错并展示 `ClientInfo.Message`；
- 若 `ClientInfo.Asyn === true`：数据量较大，转后台异步生成，提示前往 EASY「下载清单」取件；
- 否则读取 `file_guid` 与 `file_size`，拼装 `GET /AjaxServers/FileHandler.ashx?guid={file_guid}&file_size={file_size}` 走浏览器原生下载（失败时退化为内容脚本隐藏 `iframe` 触发）。

## 6. CPC / 国防官文压缩包上传与进度追踪

对应原站 `UploadProcess.aspx` / `MultUpload.js` 流程，包含以下三步：

1. **上传 `.zip` 文件分片**
   - **入口**：`POST /Forms/MultiUPload/UploadMethod.ashx?GUID={uuid}`（URL 参数大写 `GUID`，无 `Call` 参数）
   - **Body**：`multipart/form-data`，包含表单字段 `name`（文件名）与 `file`（二进制压缩包 Blob）
   - **响应特性**：服务端成功时可能返回空响应体，传输层对此路由启用 `allowEmptyJson = true`（空响应视为 `{}` 成功）。
2. **触发服务端解压分析**
   - **普通 CPC 官文**：`POST /AjaxServers/UploadFile.ashx`，参数 `Call=UploadCPCFileNew`, `GUID={uuid}`
   - **国防专利官文**：`POST /AjaxServers/UploadFile.ashx`，参数 `Call=UploadCPCFileNewGF`, `GUID={uuid}`
3. **查询解析进度列表**
   - **入口**：`POST /AjaxServers/UploadFile.ashx`
   - **参数**：`Call=GetUploadProcessList`, `pageIndex`, `pageSize`, `log_pagename=UploadProcess.aspx`
   - **响应字段**：`TableRows[]` 包含 `id`、`sn`、`zip_file_name` / `file_name`、`status`、`process`、`success_num`、`fail_num`、`create_time` / `update_time`、`remark`。
