# 专利查询与导出

来源为 `ICSearch.aspx`、`ICSearch.js`、`IhgAdvExport.js` 的原生 CDP 核对及 PatMail 接入代码。原站栏位和只读交互已核对，Excel 提交及模板写操作的回执在隔离环境验证。示例中的文号与标识均为虚构值。公共约定见 [00-通用约定.md](00-通用约定.md)。

## CaseInfo.ashx ICSearchList

用途为查询专利案件。费减按文号精确或模糊补查时复用同一 Call。完整原站字段见 [13-案件查询.md](13-案件查询.md#2-icsearchlist)。

请求示例（`Element` 仅展示文号节点，实际还带其余表单节点）：

```http
POST /AjaxServers/CaseInfo.ashx
Content-Type: application/x-www-form-urlencoded; charset=UTF-8

Call=ICSearchList
Element=&lt;case_volume&gt;EXAMPLE-001&lt;/case_volume&gt;
pageIndex=1
pageSize=20
is_proc=false
select_and=false
is_first=true
log_pagename=ICSearch.aspx
```

参数：

| 参数 | 值形态 | 说明 |
|---|---|---|
| `Element` | 实体编码 XML 片段 | 对象控件同时提交值和 `_text`；复选框仅在选中时写入；空下拉按字段传空串或 `null` |
| `pageIndex`、`pageSize` | 整数 | 从第 1 页开始。专利查询客户端每页允许 1–100 条 |
| `is_proc` | 布尔字符串 | 是否查询处理事项，影响结果列及导出栏位 |
| `is_fuzzy_query_case_volume`、`is_fuzzy_query_app_no`、`is_fuzzy_query_pct_app_no` | 布尔字符串 | 分别控制我方文号、申请号、PCT 申请号模糊查找 |
| `is_point_app_no`、`is_remove_symbol`、`select_and` | 布尔字符串 | 申请号位点、剔除符号及条件组合 |
| `is_first`、`is_top_volume_search`、`colsel`、`_t` | 开关、空串、分号列集合、时间戳 | 查询框架字段。PatMail 发送 `is_top_volume_search=` |
| `log_pagename` | `ICSearch.aspx` | 专利查询页 |

响应读取 `TableRows` 与总数。常用主键是 `case_id`，处理事项行可含 `proc_id`。行字段归一化和分页回退见 [专利查询归一化](../patmail-extension/src/api/patent-search-normalizer.ts)。

## CaseInfo.ashx GetZLLanguage

用途为初始化专利语种选择。空结果只影响该字典。

```http
POST /AjaxServers/CaseInfo.ashx
Content-Type: application/x-www-form-urlencoded; charset=UTF-8

Call=GetZLLanguage
log_pagename=ICSearch.aspx
```

参数为固定 `Call` 和页面标识。响应支持顶层数组、`Result[]` 或 `TableRows[]`。从行的 `dictionary_id`、`value`、`id` 取值，从 `text_zh_cn`、`name`、`label` 取标题。

## Report.ashx LimitMonitorGetCtrlproc

用途为按国家和管控程序读取处理事项树。期限监控原有响应见 [27-期限监控列表.md](27-期限监控列表.md#reportashx-limitmonitorgetctrlproc)。

```http
POST /AjaxServers/Report.ashx
Content-Type: application/x-www-form-urlencoded; charset=UTF-8

Call=LimitMonitorGetCtrlproc
case_type={专利案件类型GUID}
country=
proc_type=
log_pagename=ICSearch.aspx
```

| 参数 | 值形态 | 说明 |
|---|---|---|
| `case_type` | GUID | 专利案件类型 |
| `country` | 字符串 | 所选国家地区标识集合，可空 |
| `proc_type` | 字符串 | 管控程序，可空 |

响应读取 `CtrlProc[]` 并映射为树节点。

## CaseInfo.ashx ICCaseSearchToExcel

用途为按当前专利查询条件生成全量 Excel。原站在 `IhgAdvExport.aspx` 提交。PatMail 从当前同源 `GET /Forms/Patent/ICSearch.aspx` 的 WebForms 页面读取 `PageAuth`，只有该值含 `E` 且写开关打开才提交。

请求示例：

```http
POST /AjaxServers/CaseInfo.ashx
Content-Type: application/x-www-form-urlencoded; charset=UTF-8

Call=ICCaseSearchToExcel
Element=&lt;case_volume&gt;EXAMPLE-001&lt;/case_volume&gt;
is_proc=false
select_and=false
is_fuzzy_query_app_no=false
is_fuzzy_query_case_volume=false
is_point_app_no=false
is_remove_symbol=false
is_fuzzy_query_pct_app_no=false
PageAuth={当前账号权限}
orderby=
colname=
e_coulums=&lt;case_volume&gt;我方文号&lt;/case_volume&gt;
log_pagename=IhgAdvExport.aspx
```

参数：

| 参数 | 值形态 | 说明 |
|---|---|---|
| `Call` | `ICCaseSearchToExcel` | 固定动作名 |
| `Element` | 实体编码 XML 片段 | 复用专利查询条件。导出表单不发送 `pageIndex`、`pageSize` 或 `colsel` |
| `is_proc`、`select_and`、各模糊及申请号开关 | 布尔字符串 | 沿用当前查询值 |
| `PageAuth` | 字符串 | 当前登录会话的页面权限 |
| `orderby`、`colname` | 字符串 | 原站随结果排序提交。当前 PatMail 从查询控件导出时传空串 |
| `e_coulums` | 实体编码 XML 片段 | 按已选顺序拼接 `&lt;栏位键&gt;栏位名称&lt;/栏位键&gt;`。保留专利分组中同键栏位的选择 |
| `log_pagename` | `IhgAdvExport.aspx` | 审计页面标识 |

响应骨架：

```json
{
  "ClientInfo": { "IsLogin": true, "Result": true, "Asyn": false },
  "file_guid": "11111111-1111-4111-8111-111111111111",
  "file_size": 25600
}
```

- `ClientInfo.Result=true` 才视为已确认生成或受理。同步响应按 `file_guid` 和可用的 `file_size` 从 [FileHandler.ashx](46-会话与辅助接口.md#5-统一文件取件入口filehandlerashx) 取件，浏览器采用原站文件名。
- `ClientInfo.Asyn=true` 时打开原站 `Ihgforms/DownloadList.aspx`，等待原站生成。该回执表示已排队。
- `IsLogin=false` 标记会话过期。业务失败报告 `ClientInfo.Message`。模板写入与生成请求经 `patent-list-export` 工作流 WAL，按站点和 EASY 登录人隔离，传输层不自动重发生成请求。

## Common.ashx GetQueryOutConfig

专利导出用 `belong_key=ICSearch` 读取模板列表，选模板后以 `type_id` 读取栏位顺序。保存和删除调用 `UpdateQueryOutConfig`，更新调用 `UpdateQueryOutConfigNew`。请求和响应结构见 [45-清单导出与模板.md](45-清单导出与模板.md)。查询历史明细的 `QueryXml[0].out_xml` 用于导出预选栏位。查询历史入口见 [03-历史查询条件.md](03-历史查询条件.md)。

## 初始化接口与扩展消息

初始化统一发送 `log_pagename=ICSearch.aspx`。除语种外，复用以下入口：

| Handler | Call | 请求或响应要点 |
|---|---|---|
| `CaseInfo.ashx` | `IPGetBasicData` | 专利基础类型、地区及筛选枚举 |
| `BaseInfo.ashx` | `GetDeptBranch` | `BranchList` |
| `Common.ashx` | `LoadDeptTree`、`GetTreeUser`、`GetTreeAgent` | `DeptTree`、`TreeUser` |
| `PatentAction.ashx` | `GetFieldColumn` | `fieldColumn` 字段显示名 |
| `Common.ashx` | `LoadListColumn` | `belong_key=CaseInfo.ashx_CaseList`，读取 `show_column` |
| `BaseInfo.ashx` | `GetCustomField` | `table_name=p_case_info`，读取 `column_field_list` |
| `Customer.ashx` | `InitContractStatus` | 从 `table5` 读取业务合作方式 |

扩展消息为 `LOAD_PATENT_INIT`、`LOAD_PATENT_CTRL_PROC`、`SEARCH_PATENT`、`FEE_EXPORT_CONFIG` 和 `EXPORT_FEE`。专利导出使用 `EXPORT_FEE.payload.mode='patent'`，发送 `query`、`columns` 和可选 `timeoutMs`。普通查询的完整参数和导出默认栏位见 [查询参数](../patmail-extension/src/api/patent-search-params.ts) 与 [导出字段](../patmail-extension/src/api/patent-export.ts)。
