## C. 安全不变量

- 期限写入未知态拦截重复派发。明确没有开始的批次尾部保留可重试结果。已确认的历史回执仅在只读确认同一事项流程后允许新一轮提交。审核人取自绑定账号的发文规则，后台派发前仍核对写开关。
- Billing 把锚点回退或 Chrome 未知结果显示为已发起或待确认。持久化仅保存任务作用域、参数摘要、下载 ID、终态和时间。
- 隔离用例验证海牙流程和恢复，生产 eHague 与 EASY 写入均未执行。
- Agent 的出口是当前获准端点，失败时保留同端点重试策略。设置迁移要求显式批准，连接检测使用合成提示。

## F. 遗留

- EASY 缺少可将无邮件 ID 的未知意图唯一关联到某次写入的已证实只读接口。这类意图保留阻断，由人工在原站核对。文件管理继续沿用原账本，后台关闭自动重发，尚未接入期限发文的新意图槽位。
- 请款若在取得下载 ID 前丢失回执，同任务保持待核对。页面再次操作同一任务时回读已有 ID。完成侧按 24 小时复用回执，未提供历史键的全局清理。独立的 Billing 物理崩溃测试未运行，测试已覆盖适配器重挂载与默认 UI 下载。
- 部署方可用的 TLS 模型地址、企业认证代理和生产数据使用授权，状态为 **BLOCKED**。现行客户端需要配置个人模型凭据和获准端点。真实 EASY、WIPO 写入验收为 **NOT RUN**。

## G. 验收结论

**PASS WITH LIMITATIONS**。在隔离测试覆盖的工作流中通过验证。生产写入、企业模型部署条件和无法唯一归属的回执核对仍受上述限制。
