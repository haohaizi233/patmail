# Agent 模型服务安全 ADR

## 决策

采用本机个人凭据和单一端点。内置 Qwen 的固定模型名称和地址默认批准，发布包仍无共享 Key 或备用 Key。原构建可从 `VITE_AGENT_DEFAULT_KEY` / `VITE_AGENT_FALLBACK_KEY` 注入共享凭据。产物门禁同时运行通用秘密扫描，并在构建环境仍提供旧变量时匹配其中的实际值，报告只包含文件名。旧发布包的分发和凭据轮换由部署方核查。

自定义地址首次连接前须在设置页确认。已有地址、Key、模型和思考设置由原键读取。命中内置模型及固定地址的旧配置自动取得批准并保留本机 Key。更换地址时须输入该服务的个人 Key。Key 存在当前扩展的 `chrome.storage.local`，本机操作者和具备扩展访问权限的进程可以访问该配置。

## 数据出口与信任边界

| 目的地 | 默认行为 | 连接条件 |
|---|---|---|
| 内置 Qwen | 固定模型和 `http://43.138.138.200:8588/v1` 默认批准 | 使用本机 Key。此例外通过明文 HTTP 发送凭据和模型请求 |
| 本机回环模型 | 无默认连接 | 明确批准，使用个人凭据。自定义 HTTP 仅允许回环 |
| 其他 HTTPS 模型 | 无默认连接 | 明确批准，使用个人凭据，以及浏览器已有站点权限或服务器 CORS 支持 |
| MiMo | 无自动切换 | 用户可以主动选用该 HTTPS 服务并单独批准，保留已有主机权限和 API 协议 |

旧故障转移会向备用服务发送当前模型请求，包括对话、工具结果与上下文。现行请求固定到批准的端点，禁止重定向，省略浏览器 Cookie 和 Referer。探测只发送固定合成提示。模型请求、工具记录及返回内容清除已知当前模型 Key 和可识别的认证头、Cookie、密码与令牌字段。工具所需的案件、客户和文档信息仍可能进入获准模型的上下文，操作者须遵守部署方保密策略。服务错误只报告归类和状态。

## 待部署方确认

当前没有可独立验证的旧端点 TLS 入口、企业认证代理或服务端授权。企业网关地址、TLS、会话凭据与数据保留策略标记为 **BLOCKED**。生产服务的连通和数据授权应在部署方提供环境后单独验证。未使用生产材料探测。
