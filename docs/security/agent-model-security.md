# Agent 模型服务安全 ADR

## 决策

采用本机个人凭据和明确批准的单一端点。发布默认地址、默认 Key 与备用 Key 均为空或已删除。原构建可从 `VITE_AGENT_DEFAULT_KEY` / `VITE_AGENT_FALLBACK_KEY` 注入共享凭据。产物门禁同时运行通用秘密扫描，并在构建环境仍提供旧变量时匹配其中的实际值，报告只包含文件名。旧发布包的分发和凭据轮换由部署方核查。

首次连接前在设置页保存并确认具体地址。已有个性化地址、Key、模型和思考设置由原键读取，已有证书条件仍适用。没有批准标记的历史配置须重新确认。更换地址时须输入该服务的个人 Key。Key 存在当前扩展的 `chrome.storage.local`，本机操作者和具备扩展访问权限的进程可以访问该配置。

## 数据出口与信任边界

| 目的地 | 默认行为 | 连接条件 |
|---|---|---|
| 旧公网 HTTP 模型 | 无默认连接，已移除对应主机权限 | 由部署方提供确认可用的受信 HTTPS 地址 |
| 本机回环模型 | 无默认连接 | 明确批准，使用个人凭据。HTTP 仅允许回环 |
| 其他 HTTPS 模型 | 无默认连接 | 明确批准，使用个人凭据，以及浏览器已有站点权限或服务器 CORS 支持 |
| MiMo | 无自动切换 | 用户可以主动选用该 HTTPS 服务并单独批准，保留已有主机权限和 API 协议 |

旧故障转移会向备用服务发送当前模型请求，包括对话、工具结果与上下文。现行请求固定到批准的端点，禁止重定向，省略浏览器 Cookie 和 Referer。探测只发送固定合成提示。模型请求、工具记录及返回内容清除已知当前模型 Key 和可识别的认证头、Cookie、密码与令牌字段。工具所需的案件、客户和文档信息仍可能进入获准模型的上下文，操作者须遵守部署方保密策略。服务错误只报告归类和状态。

## 待部署方确认

当前没有可独立验证的旧端点 TLS 入口、企业认证代理或服务端授权。企业网关地址、TLS、会话凭据与数据保留策略标记为 **BLOCKED**。生产服务的连通和数据授权应在部署方提供环境后单独验证。未使用生产材料探测。
