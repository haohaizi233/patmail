后续修复进展：本报告记录的是当时的验收状态。登录中断漏页、ref计数等问题已在v1.4.2处理，最新真实重查询基准和修改见 [文件管理全选性能修复](file-query-performance-2026-10-27.md)。

## 结论

并发源码确实能并发，但验收开始时可加载的构建产物仍是旧版，完整浏览器测试的实际峰值只有 1。重新构建后，同一套完整插件测试的峰值为 6；独立浏览器登录真实原站后，通过工作台消息、后台和内容脚本发出的 6 个受限查询也确实同时在途。

本轮重新生成了 `dist`，增加了浏览器验收脚本，没有修改 Cursor 的生产源码。另确认登录中断后的待重试页列表不完整、完成提示错误计数两个问题，尚未修复，不能据并发通过宣布整体验收通过。

## 未通过的两个检查

### 登录中断时，未开始的页没有进入待重试列表

位置：[page-pool.ts](../src/app/page-pool.ts)，`sessionDown` 与 `missed` 的处理。

隔离调用真实 `runPagedFetch`，页码为 1–8，并发数为 1，第 2 页返回 `{ ok:false, session:true }`：

```json
{
  "called": [1, 2],
  "missed": [2],
  "unattempted": [3, 4, 5, 6, 7, 8]
}
```

登录中断后停止发新请求是合理的，但返回值遗漏了尚未读取的页。调用方仅针对 `missed` 兜底与重试，可能重试第 2 页后显示已补齐，实际仍缺第 3–8 页。默认 6 路时，页数多于已派发任务数也存在同类问题。现有串行登录中断用例反而将 `[2]` 写成预期，没有覆盖未派发页的完整性。

### 完成提示统计的是 Vue ref 对象

位置：[FileSearchQuery.vue](../src/app/components/FileSearchQuery.vue) 的全选成功提示，使用了 `Object.keys(selected).length`，脚本内应取模型值。

完整浏览器复跑确认：界面选中统计为 140 个文件，但完成提示为“已全选 5 个文件。”。这不是实际丢了 135 个，而是完成提示统计了 ref 对象自身的属性。

## 专利标签的独立核对

### 已确认的事实

- 重新读取原站公开 `FileSearch.js`，与留存版本 SHA-256 一致：`07103d4144503f2690cdc9eab7a7077343730567078fc2c24611a66d55a95543`。
- 原站 `FileSearch.js:871–876` 将 `ApplyTags[].id/name` 交给 `#apply_tags_id.TreeUser`，`SelectType:"checkbox"`；查询提交读取 `attr("objid")`。它按设计是可搜索的多选下拉，提交内部 ID。
- 插件 `isMultiPickerKey('apply_tags_id')` 为 true，正常勾选值按逗号拼接，与原站一致。
- 原站期限页同样使用 `CaseInfo.ashx / GetApplyTags` 和 `ApplyTags`，因此不能仅因文件查询页使用 `IPGetBasicData` 就认定插件接错接口。
- 本次已登录账号的实时 `IPGetBasicData`、`CaseInfo.GetApplyTags` 均成功返回 `ApplyTags:null`。在主框架内加载文件查询页，输入元素带 `tree_id="tree_apply_tags_id"`，可编辑、非 readonly，但没有初始化标签树。这是当前账号无标签数据的实测结果，不是只根据历史 HAR 推断。

### Cursor 结论需要收窄的部分

修改前静态 `form-layout.ts` 已将专利标签登记为 `named`，动态扫描字段主要追加静态布局里未登记的项。因此，修改扫描器、快照和动态字段分类是正确方向，但不能据此断言截图对应的插件控件原先一定是文本框，或标签功能已完整修好。

另外隔离复现了两条未闭合的异常路径：

1. 扫描器拿不到 zTree API 时，DOM 降级分支将显示名称当作 `value`。提供标签 DOM、不给 zTree API，真实扫描器得到 `{value:"标签A",label:"标签A"}`；真实查询参数构建器可原样提交 `apply_tags_id=标签A`。本次改为 picker 后，该选项有机会进入缓存和渲染流程。当前账号没有标签，未在真实页面验证这条带标签分支。
2. 实时字典成功返回空列表时，`optionsFor` 仍可能回退到旧账号缓存；缓存保存函数也拒绝空数组。先存旧标签，再返回权威空字典的隔离测试中，已删除标签仍会显示。这是已有缺陷。

不能把上述隔离复现说成当前真实账号已触发，也不能将历史 `PatentAction.ashx / GetApplyTags` 的 `TableRows` 响应混作 `CaseInfo.ashx / GetApplyTags` 的 `ApplyTags` 响应。
