# 期限监控

期限监控既是独立页面（侧边「期限监控」），也内嵌在按工作流发文页里。两边同一套查询和提交。

## 查询表单

| 控件 | 作用 |
|---|---|
| 类型按钮组（全部/缴费/中止/放弃/撤回/优先权/费用） | 按处理事项类型过滤；「流程」页签是预留位 |
| 我方文号 | 一个文号，或多个用分号、空格、换行隔开 |
| 申请号 | 按申请号查 |
| 客户名称 | 按客户名称查 |
| 重置 | 清空全部条件 |
| 查询 | 执行查询 |
| 模板下拉 | 套用查询模板页保存的条件 |

「查询条件」一屏跟原站同序：我方文号到业务人员是上半段，业务助理、流程人员、委案日期、处理事项备注、专利标签、处理事项处理人所属部门、客户文号和自定义栏位 1–5 是原站表单尾部那一排，也直接放在这一屏，不再收进「更多条件」。更多条件里是原站默认折起来的日期组：案件处理人助理、文件上传日期、代理人回复日到第三方确收日、客户全称。

自定义栏位 1–5 的业务名由租户在 `GetFieldColumn` 里配置，表单标题按接口返回的 `column_name` 显示（例如「立案流程编号」「月结 特批单号」「收款日期」「签约主体 即 世纪恒程 恒程创新」「收款账户」）；接口没给名字时退回「自定义栏位1 / 特批编号 / 回款日期 / 业务立案编号 / 所属部门」。提交参数仍是 `column1` 到 `column5`，模板里按原站控件名 `column_1` 到 `column_5` 存回。

日期格都是日历框（点输入框弹日历，清空 / 今天 / 确定跟原站 `WdatePicker` 一致，起止两格用 min / max 互限）；申请日(月日) 一格没有年份，日历回填 `MM-dd`。

下拉选项从原站实时读：人员（业务助理、流程人员、核稿人、处理事项处理人等）走 `GetTreeUser`，处理事项处理人所属部门和承办部门走 `LoadDeptTree`，专利标签走 `GetApplyTags`，国家、业务类型、申请类型、案件状态等走 `LimitMonitorInit`。这些来源见 [API/09-期限监控.md](../../API/09-期限监控.md) 和 [API/02-公共数据.md](../../API/02-公共数据.md)。

## 列表

列依次是：勾选框、我方文号、案件名称、处理事项、客户、申请号、官方期限、客户期限、内部期限、流程状态。

流程状态的配色：蓝色是还没提交审核，灰绿是已发文未管制完成日，紫色是不用发，绿色是已经审核完成，橙色是已提交审核，灰底是库里没有或没查成。

## 勾选与提交

| 按钮 | 作用 |
|---|---|
| 全选本页 / 全选所有 / 全选所有（非补非仲） | 只勾还能提交的行；已提交审核、不用发、发过的不能勾 |
| 提交到 EASY | 按当前勾选提交：有名字的行按写回收件人，空着的行按发文规则勾选联系人兜底 |

写开关关着时会直接提示「写开关在系统设置里关着，没有提交到 EASY」。

审核人统一来自当前账号的「发文映射 → 默认审核人」，独立期限页面和内嵌期限表采用同一来源，不再自动选当前登录人。未配置时在创建前阻止提交；配置人员不在下一节点候选列表、或不能按 GUID 唯一匹配时，保留草稿并提示原因，不回退到其他人。当前登录人只用于确认操作账号和会话。
