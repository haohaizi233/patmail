# 查询模板

把常用的查询条件存成模板，文件查询、期限表和递交管理的表单里可以直接套用。

| 按钮 | 作用 |
|---|---|
| 文件管理 / 期限监控 / 递交管理 | 切换维护哪一类模板 |
| 模板下拉（EASY / 本地） | EASY 模板从原站读取，本地模板存在插件里 |
| 新建本地模板 | 从一张基础模板复制出本地模板再改 |
| 各条件行 | 文号、日期起止、客户等；留空的项保存后会被清空 |

文件查询和期限监控的日期起止都是日历框（点输入框弹日历，起止互限）；期限的「申请日(月日)」只写月日，格式 `MM-dd`。

期限表单选模板后条件自动填进去，改完还能另存。

递交管理的模板只存在本机：原站的递交列表没有模板功能，保存和删除都不写原网站。模板按卡片列在查询条件上方，点一下就把条件填回表单，再点一下取消选中。在递交管理页填好条件，写上模板名点「保存到本地」；改完条件点「更新模板」覆盖回去，「删除模板」只删本机这份。

递交管理还有一个随扩展内置的模板「退回」（处理事项=新申请、客户自撰，办理类型=退回），标「内置」徽标，谁登录都能点，不能改也不能删。它只覆盖这两项条件，其余条件留着你自己的填法；要改就套用后改条件，点「保存到本地」存成自己的模板。处理事项这类下拉没读到时先点「校对最新字段」再套用。

## 文件描述的展示与清洗

套模板带过来的文件描述偶尔混着名字、空段或中文逗号（原站模板里就有这种）。查询前插件会先换回内部 ID：名字按当前案件类型的文件描述树对，对不上的项会在查询条件下方点名提示，查询只带上换得上的部分，不再整条报「文件描述必须使用内部 ID」。选中的文件描述超过 10 个时，摘要只摆前 10 个并标「共 N 项」，点「展开全部」看完整清单，鼠标停上去也有全文提示。

## 下载名称与下载已选

文件查询表单里的「设置下载文件名称」选下载名称模板（模板存在原站账号上，填好「模板名称」点「保存下载名称」就存到账号上，「删除下载名称」删除当前选中的模板，同名模板原站允许存多份）。选中的名称不参与查询：查询结果里勾选文件后点「下载已选」，用来生成压缩包里的文件名；文件管理工作流发文时也用它生成附件名。不选就用查询结果里的附件原名。勾选和其他工作流一样用「全选本页 / 取消全选本页 / 全选所有 / 取消全选所有」：全选所有会逐页把行拉回来勾上，翻页时顶栏有彩虹进度条；**下载数量不设上限**，有多少下多少（打包下载不再显示进度条，按钮会变「正在打包下载…」）。**查询出结果之后再改这里也不用重新查**：点「下载已选」的一刻才读表单当前值（按钮悬浮提示会写明这次按哪个名称生成），而且会再向原站拉一次该模板的最新配方，改了模板内容也按最新的来。

「下载已选」旁边有「申请号去点」勾选，默认勾上：下载下来的压缩包里，文件名的申请号会去掉校验点——`202610026334.9-清洗液监测系统及其监测方法-专利申请受理通知书.pdf` 变成 `2026100263349-清洗液监测系统及其监测方法-专利申请受理通知书.pdf`。只动申请号里的那个点，扩展名和其他小数点不动；不想改名就取消勾选，文件名原样下载。压缩包另存成「下载文件-年月日-时分秒.zip」，包里每个文件都带对应的名字，这次下载会正常出现在浏览器的下载记录里；有文件没打包进去时，结果行会带出原站的失败提示。打包下载进行中，顶栏会出现和任务核对同一条的彩虹进度条（一次请求没法按件数报进度，用不定长彩虹条加阶段文案），下载完自动收起。同案件同名的旧版本会自动过滤，压缩包里只留上传时间最新的一份，判定规则和边界见 [下载去重算法](16-下载去重算法.md)。
