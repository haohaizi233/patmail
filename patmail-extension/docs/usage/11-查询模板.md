# 查询模板

把常用的查询条件存成模板，文件查询、期限表和递交管理的表单里可以直接套用。

| 按钮 | 作用 |
|---|---|
| 文件管理 / 期限监控 / 递交管理 | 切换维护哪一类模板 |
| 模板下拉（EASY / 本地） | EASY 模板从原站读取，本地模板存在插件里 |
| 新建本地模板 | 从一张基础模板复制出本地模板再改 |
| 各条件行 | 文号、日期起止、客户等；留空的项保存后会被清空 |

文件查询和期限监控的日期起止都是日历框（点输入框弹日历，起止互限）；期限的「申请日(月日)」只写月日，格式 `MM-dd`。

期限表单选模板后条件自动填进去，改完还能另存。

递交管理的模板只存在本机：原站的递交列表没有模板功能，保存和删除都不写原网站。模板按卡片列在查询条件上方，点一下就把条件填回表单，再点一下取消选中。在递交管理页填好条件，写上模板名点「保存到本地」；改完条件点「更新模板」覆盖回去，「删除模板」只删本机这份。

递交管理还有一个随扩展内置的模板「退回」（处理事项=新申请、客户自撰，办理类型=退回），标「内置」徽标，谁登录都能点，不能改也不能删。它只覆盖这两项条件，其余条件留着你自己的填法；要改就套用后改条件，点「保存到本地」存成自己的模板。处理事项这类下拉没读到时先点「校对最新字段」再套用。
