# 工作流配置

侧边「工作流」进去。左边是流程列表，右边是画布。

| 按钮 | 作用 |
|---|---|
| 新建工作流 | 打开技能面板搭一条新流程 |
| 技能气泡（读取表格、对收件人、提交审核等） | 点一下把这一步加进流程 |
| 步骤节点 | 点选后在下方编辑这一步的参数（叫什么、写成、说明） |
| 上移 / 下移 | 调整步骤顺序 |
| 删除步骤 | 移除自定义步骤（内置步骤不能删） |
| 加一句说明 | 给步骤补备注 |
| 预览 | 打开流程预览图，点节点查看对应配置 |
| 复制 | 复制当前工作流 |
| 保存 | 保存草稿。系统内置的工作流锁着不能改，复制一份再改 |
| 删除 | 只能删自己建的 |

PCT提醒、PCT鹏城专案和文件管理是三条内置工作流，步骤齐全，缺步骤的工作流不能生成预览。

「谁来看一眼」统一使用发文映射里配置的默认审核人，这里只显示来源；修改审核人请到「发文映射」。不会以当前登录人作为兜底。

「文档 → 工作流」按一条工作流一篇 Markdown 展示，README 为索引。Mermaid 正文图默认铺满可用宽度、高度自然增长；点击「放大查看」可单独缩放、拖拽，并切换适应宽度或适应窗口。
