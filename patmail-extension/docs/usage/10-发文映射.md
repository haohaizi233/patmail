# 发文映射

维护文件描述、处理事项到发文类型的映射，以及各客户的收件人和签名。

| 区域 | 作用 |
|---|---|
| 文件描述 → 发文类型 | 来文上的文件描述对上 EASY 的发文类型，一条描述一行 |
| 处理事项 → 发文类型 | 工作表中的处理事项按文号条件选择发文类型，支持从原站树选择具体叶子、导入和导出 |
| 收件人 | 按客户配默认收件人 |
| 默认发件邮箱 | 按客户配默认发件邮箱 |
| 默认审核人 | 按客户配默认审核人 |
| 签名 | 默认签名和操作员签名，自选任务的签名下拉从这里读 |
| 客户发文策略 | 按客户选查询方式（文件查询/期限监控）和发文方式，可存多套并写备注 |

文件管理的工作流和自选任务依赖文件描述映射；按工作流发文读取处理事项映射。按各区域的添加、保存或删除按钮提交修改，结果以页面提示为准。

## 处理事项映射

PCT 提醒、PCT 进国家阶段官方绝限和涉外外观提醒使用内置映射，按有无客户文号选择贵方案号或我方案号的发文类型，不能在表格里修改。

自定义项先选原站的具体处理事项，再选文号条件（无、有客户文号、无客户文号使用我方文号）和发文类型的完整树路径。优先使用对应文号条件的映射，没有时使用条件为「无」的映射；同一事项、同一条件不能重复添加。

可以导出当前映射，或从含「处理事项」「发文类型」「文号条件」的表格导入。导入整表校验成功后才保存；内置项跳过，已有不同映射会提示先删除原项。两张映射表都支持搜索和分页。
