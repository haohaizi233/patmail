# 知易通域名会话恢复

四个入口均通过所在原站内容脚本调用 `/AjaxServers/Login.ashx` 的 `GetUserModel`。大客户允许 183.36.43.66 与 d.hiseeip.com，中小客户允许 183.36.43.44 与 z.hiseeip.com；实际请求与账号数据保持完整 origin 隔离，不复制登录凭据。

2026-11-16 修复：

- 首次连接时前端原本只期待客户模式的默认 IP，因此后台成功识别域名账号后，前端仍丢弃响应。现在仅在发现/显式绑定阶段接受当前模式精确允许的来源；已连接账号和写回执仍严格检查原来源、请求世代及身份。
- 重开登录及关闭标签页后保留实际绑定的域名，不回退到另一浏览器会话的 IP。
- 会话失效由顶层 webNavigation 触发，内嵌页面 loading 不再清空身份。
- 同标签页、同连接版本的并发检测合并；后台等待 35 秒，覆盖内容端 30 秒请求预算。
- 桥接丢失时合并脚本重注入。页面/账号世代变化时不重发旧业务消息。移除会话响应调试输出。

验证：290 个测试文件、2015 项测试通过，构建/类型检查及变更文件 ESLint 通过。原生 CDP 现场确认 d、z 均返回 authenticated；分别刷新后后台仍绑定各自域名，工作台显示已连接。探针只输出会话摘要，不记录 Cookie、请求头或用户模型。未操作业务写入。
