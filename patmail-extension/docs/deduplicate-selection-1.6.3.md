# 搜索结果默认过滤同名附件

用户要求：结果区增加默认开启的重复过滤；全选时保留离现在最近的结果。按截图上传时间判断最新，不用官方发文日。用户ZIP的788条目里，忽略自动数字后缀并把doc/docx视为同类，可识别183组重复；此分析仅看目录，未解压或执行附件。

实现选择：筛选勾选项，保留查询原始行和分页总数，便于关闭筛选后查看/选择旧版本。选项名“同名文件仅保留最新”，默认开启；全选本页作用于已知候选，全选所有完成全部分页后跨页比较，后返回的新文件可替换先返回的旧文件。没有读取的页不虚构已比较。关闭后再次全选可包含所有版本。

分组必须有同一案件身份（caseId优先，其次客户+我方文号或申请号）；同名比较忽略尾部自动追加的空格数字括号，以及doc/docx扩展名差异。PDF和Word不合并，不同原始正文名不猜为重复；无案件身份的文件独立保留。相同或缺失时间以稳定文件ID打破平局，不依赖并行页返回顺序。

查询选中项携带原始uploadTime与caseId。开关写入工作面恢复快照；已有暂停下载的冻结清单保持不变。去重只裁剪本地勾选，不删除原站附件，也不改用户已有压缩包。

验证关注：跨案件同名保留、doc/docx、数字后缀、跨页乱序新旧、无效时间、关闭筛选、恢复开关、已有下载冻结清单。
