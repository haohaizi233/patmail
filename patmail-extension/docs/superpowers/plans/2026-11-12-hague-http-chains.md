# 海牙纯请求链与状态隔离

用户要求深入逆向，复用 CDP、登录态和既有请求证据，减少每案标签页，以独立 HTTP 链并发完成草稿。继续现有草稿范围，不递交、不付款。

方案：每案内存上下文持有独立 DOM/ViewState、路径、reference、上传表格和请求锁；共享的仅是浏览器凭据及有界网络池。复用既有字段填写逻辑，但在脱离实际页面的文档中运行，通过安全解析原站 PrimeFaces 配置产生直接 JSF POST，不执行任意响应脚本。每次响应只更新本上下文；失败不重试不确定写入。

验证顺序：先测试上下文、partial update、串行锁与交错隔离；用原生 CDP 研究创建/字段/上传；再做真实草稿验证并核对编号及列表。完整协议未通过前不将未验证操作静默回退到实际页面，更不能声称完整链已通过。Summary 原站只有 window.print 的情况需单列输出边界，不能虚构 PDF API。
