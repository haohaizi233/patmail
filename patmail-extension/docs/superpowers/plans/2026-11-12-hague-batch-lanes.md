# 海牙批量草稿：独立标签页与 1–6 路调度

用户要求接通批量填写并研究六路并发。保留单案的有状态 JSF 顺序执行器，将案间调度提取到独立模块；不在同一个文档中交错两案。

## 实现与验证

1. `src/hague/draft-batch.ts`：有界 worker、行级预检查、失败隔离、停止、不确定写入不重试、每案检查点、聚合实际步骤计数；先测试并发上限、空闲槽立即补案、恢复同标签页、单案失败。
2. `src/hague/draft-tabs.ts`：新案创建后台 portfolio 标签页并等待加载、验证登录；恢复使用检查点的原标签页；成功完成后复用本 worker 的 portfolio 页面，不关闭未完成现场。不同 worker 必须不同 tabId。
3. `HaguePage.vue`：接批量按钮、并发选择、成功/异常/跳过/活动路数与逐案进度；单案仍使用用户选定标签页。保留原有样式组件。
4. 原生 CDP 只读实验：同一登录下打开六个独立 portfolio 页面，检查页面/会话及 ViewState 可用性，结束只关闭本次创建的测试标签页。该实验不等于六路写入压测；没有对应证据不宣称六路真实业务验证成功。
5. 单元回归、隔离 UI 回归、构建与 lint 基线；更新工作流和接口文档，说明边界。不得正式递交或付款。

## 约束

并发是案间，不是单案二十多步之间；网络/上传、导航、PDF 都等待本案回执。登录失效停止领取新案并保留现场。无有效材料的案件显示跳过原因，不因一个不可用案件阻止整批。已保存草稿不重复创建。默认串行，用户可选至六路；真实六路写入稳定性未验证前明确标为试运行。

## 验证记录

- 扩展实际开页只读实验：6/6 登录有效、6/6 完成加载、6 个不同 JSF ViewState，约 18.2 秒；无业务写入，测试页已关闭。
- 隔离 UI：单案双申请人/双设计，以及 7 案/6 路、112 图、独立签名文号、保存回执、工作页复用、顶部进度均通过。
- 修正真实 Chrome 大标签页 ID 被 `<10000` 误拒绝的问题；标签页互斥在第一次 await 前获取，失败的重复调用不释放持有者锁。
- 独立审查发现并修正“续跑成功后保留标签页 reservation 导致后续新案误拒绝”，已补失败再通过的回归。
- 海牙单元回归 106 项通过；构建及 lint 基线通过。真实六路完整写入及服务端限流仍未压测。
