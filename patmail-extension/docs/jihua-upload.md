# 计划实验室-文件导入

入口是“工作流”中的“计划实验室-文件导入”卡片，在工作流页面内打开，支持“回到工作流”。返回或切换工作台页面保留该组件和任务进度。页面复用工作台的 PageHead、ThemeSelect、卡片、表格、按钮和卡哇伊主题。需要 Chrome/Edge 的 File System Access、IndexedDB 和 Web Locks 支持。

## 使用

1. 点击“添加文件夹”，分别选取 `D:\MemoryLeak\下载\大客户`、`D:\MemoryLeak\下载\中小客户` 或其他来源目录。支持目录嵌套和目录内直接放文件；浏览器授权以目录选择器为准，不能在页面中直接读取任意文本路径。
2. 扫描阶段只枚举名称和相对路径，不调用文件 `getFile()` 或读取正文。默认纳入 PDF、DOC、DOCX，可以取消不需要的类型；ZIP、MAL、XML 等始终排除。相同目录再次添加会合并清单，保留选择、材料映射和上传回执。缩小范围后的旧记录保留历史但取消选择。
3. 查看“按申请号预览”和“文件明细”，勾选需要处理的材料。文件名按 `申请号-案件名称-文件描述.扩展名` 解析，保留案件名中的连字符。未知描述可手工选目标材料；未匹配的行有独立结果，其余行继续处理。
4. 在浏览器打开并登录 `https://oa.jihualab.net`，回到工作台选该标签页并点击“连接并检测登录”。网络使用该浏览器的 VPN/代理环境。平台用户身份与 EASY 账号分别管理，不会把季华平台当作 EASY 租户。
5. 点击“开始上传”。六路并发按申请号分配，同一申请号内串行保存。“暂停上传”停止派发新工作并等待当前请求；“取消任务”中止本地等待和后续派发，保留行记录、已发送标记和原始回执。扫描、连接或上传等待过程中都可取消。
6. 表格逐行显示正在核对、正在上传、正在关联、正在回读，以及上传成功、上传失败、已经传过、没匹配到。可导出带 BOM 的 CSV，包含选择、来源、材料、状态、错误和附件 ID。
7. “新建任务”会先取消当前本地工作，将当前任务完整移入历史，再打开空白任务；未确认回执不会阻止创建新任务。右侧“历史任务”可恢复最近 50 条记录，恢复时当前任务也会保留到历史。历史记录保留原有选择、材料映射、文件句柄和回执，恢复后由用户继续上传。

主区域复用工作台的白板卡片、工具栏、分页和局部滚动表格；右侧复用 `with-rail` 设置栏。状态和任务操作固定在表格上方，按申请号汇总可折叠查看。页面沿用公共主题变量、PageHead、ThemeSelect 和全局顶部进度条。

## 幂等与恢复

- 搜索参数使用 `PATENT_NUM`，遍历返回页后按标准化申请号精确核对唯一案件，不选择模糊搜索的第一行。
- 同类已有附件时整类跳过，不读取对应本地文件。“递交合并档 / 递交文件合并档 → 专利请求书”“新申请文档 → 申请文件”；“费用减缴审批通知书”、著录项目变更手续合格通知书、实用新型证书签章有明确别名规则。旧任务中此前未识别的这些描述会在读取时补齐映射，保留原有选择和回执。
- 本地目录/文件句柄和任务元数据存在扩展自己的 IndexedDB；扫描不会复制文件正文到任务存储。只在选中的文件实际需要上传时读取字节，并检查基本文件头，拒绝明显的网页响应或格式不符。
- 已上传附件 ID 先持久化，再回读最新表单合并附件列表，保留其他材料和业务字段。只有保存后详情中确认 ID 存在才标记上传成功。不调用附件删除，不自动改变业务开关或 OCR 业务字段。
- 上传回执丢失时查询原 requestId，不重新发送 multipart。原页面已重载且没有回执时标记详细错误；需人工核实后显式决定是否重新上传。关联失败保留已上传 ID，继续时先回读再关联。
- 取消只停止本地等待，已到达平台的请求可能稍后完成，原页面会保留其回执供恢复核对。迟到响应不能覆盖新任务；刷新后的运行状态会先核对实际执行锁，没有执行者的任务恢复为暂停，取消和新建仍然可用。
- 新任务重扫同一目录时，相同路径、文件名和申请号会沿用历史已发送请求、原材料映射及回执，防止通过新建任务或重新映射意外重复上传；不会复制历史勾选。若原路径文件已被替换，需先人工核实旧请求。其他账号的发送记录会阻止该行跨账号关联，其余材料继续处理。
- 平台 HTTP 408 / 429 / 5xx 或请求超时会暂停新任务派发；最多保留当时已进入流水线的六路请求等待回执，避免持续扩大未确认上传。上游返回 HTML 错误页时仍保留 HTTP 状态。HTTP 524 不能证明服务端没有收下文件，因此已发送的上传不会自动重传。
- 工作台关闭或刷新后从检查点恢复为暂停，重新连接并授权目录后继续。扩展 Service Worker 重启不丢目标页面仍保留的请求回执。跨工作台用 Web Lock 防止重复运行；同一平台用户重新登录可重新连接后恢复，切换到其他用户会阻止续写。
- 浏览器页面内按 256 KiB 暂存块组装原站单文件 multipart，服务端没有被假定存在分块接口。传输具有暂存字节预算，大文件可能降低实际并发，避免同时组装六份大文件。
- 当前客户端单文件暂存上限为 256 MiB，属于本地内存保护，不代表平台服务端限制。超过时该行给出详细错误，可在原站手工上传；其他行继续。已持久化的回执会从目标页及时释放，未确认的写入回执继续保留。

## 范围与边界

目前自动匹配 13 位中国申请号，支持已经核对页面契约的发明、实用新型台账。发明 39 个上传材料/40 个保存字段，实用新型 30 个上传材料/31 个保存字段；实用新型证书和驳回决定使用普通上传。外观、PCT、软著及旧式申请号会明确显示没匹配到。

普通上传界面每类上限 10 份，OFC 识别类上限 1 份。同一申请号选择超过上限时要求调整，不随意选一份。未启用的一般申请、快速预审、优先审查材料分组会提示用户在平台确认，工作流不自动改业务标记。

平台保存接口的后端版本锁/事务语义尚未得到证实。每次写前回读并完整保留附件，可防止本任务自己的并发覆盖；外部人员恰好同时编辑仍存在平台本身没有版本锁的竞争窗口。服务端格式/大小限制、真实 VPN 下的超时和实际上传响应，需要真实平台验收补充；模拟测试不代替该验收。
